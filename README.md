# Smart Medical Bracelet (IoT Health Monitor) 🩺⌚

An integrated mechatronics and IoT project focused on designing a wearable medical bracelet for continuous health monitoring. This project encompasses the full product development lifecycle, from system modeling to hardware design and mobile application deployment.

---

## 🚀 Key Engineering Dimensions

*   **Systems Engineering (SysML):** Comprehensive system architecture modeling (Requirements, Block Definition, and State Machine diagrams) to define functional relationships and data flow.
*   **Hardware Architecture (PCB Design - Eagle):** Custom printed circuit board design integrating vital sign sensors, power management, and wireless communication modules (IoT/Bluetooth).
*   **Mechanical & CAD Design (3D CAD):** Ergonomic and durable wearable casing designed for comfort, optimal sensor placement against the skin, and manufacturability.
*   **Software & Connectivity (Mobile App):** A dedicated companion mobile application developed to receive, process, and display real-time telemetry data from the bracelet.
